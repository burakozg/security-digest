Recipients

Who receives this instance's digests. One digest is built per recipient, containing the topics addressed to them below plus every topic set to All recipients. Stored in data/users.yaml and edited here — there is nothing to deploy and nothing to keep in sync. A recipient with no topics gets no email at all rather than an empty one.

Topics

Entities tracked by news search (Google News + Bing News). Stored in data/topics.yaml and edited here — there is nothing to deploy and nothing to keep in sync. Each digest in config.yaml lists topic names that must match the names here — the Digests column is read-only and shows which digests pick each topic up; a topic showing “—” reaches nobody. Context is what the model uses to reject same-name-different-subject results, so it is worth writing carefully.

RSS sources

Feeds are saved to data/sources_overrides.yaml so sources.yaml can stay read-only. The initial list still comes from sources.yaml until you save here (then overrides replace the full RSS list). Tick the Digests a feed should reach — each digest's source list is derived from these ticks, so routing is set here and nowhere else. An item still has to be categorised into one of that digest's sections to arrive; the routing table below shows which combinations actually land.

Routing table

Delivery needs every filter to match, so what matters is the combination. A cell shows which digest would take an item from that feed with that value — nowhere means such an item is summarised at full cost and then discarded. Updates automatically when you save sources.

AI prompts

Edit the prompts used for categorisation and digest generation. The values below are enforced on the model's answer by the API, and set in config.yaml — a prompt that teaches a different name will have its answers silently replaced by the fallback, so change both together.

LLM provider & model

Choose OpenAI, Anthropic, Mistral or OpenRouter and a model. Recommended picks are grouped at the top.

OpenAI: OPENAI_API_KEY in .env. Anthropic: ANTHROPIC_API_KEY. Mistral: MISTRAL_API_KEY. OpenRouter: OPENROUTER_API_KEY. Saving writes data/llm_overrides.yaml so config.yaml can stay read-only.
